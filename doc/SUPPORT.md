# Support — sevenx_themes_media

## Bug reports and feature requests

Please open an issue on GitHub:

- https://github.com/se7enxweb/sevenx_themes_media/issues

Include your Exponential and PHP versions, the siteaccess name, the template
path involved (from `ShowUsedTemplates` debug output where possible) and a
URL that reproduces the rendering problem.

## Security issues

Do not open public issues for security vulnerabilities. Report them privately
by e-mail to info@se7enx.com.

## Commercial support

Commercial support, custom development and hosting for Exponential
installations are available from 7x:

- https://se7enx.com
